# Coco Dental

A modern responsive dental clinic landing page built with HTML, CSS, and JavaScript.

## Project structure

- `index.html` — homepage structure
- `styles.css` — design and responsive layout
- `script.js` — mobile nav and form interaction

## Run locally

Open `index.html` in a browser, or serve the project with a simple local server:

```bash
cd dental-clinic-site
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## GitHub push

Initialize git if needed:

```bash
git init
git branch -M main
git add .
git commit -m "Initial commit"
```

Then create a GitHub repository and push:

```bash
git remote add origin https://github.com/YOUR_USERNAME/YOUR_REPO_NAME.git
git push -u origin main
```
